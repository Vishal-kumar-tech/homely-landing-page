# Homely 🏠 | Stay Booking Website (Frontend)

A responsive landing page for an accommodation booking website, built using **HTML and CSS**. Users can explore different types of stays (villas, apartments, mansions, cottages) with details like rating, price, amenities and a Book Now option.

🔗 **Live Demo:** [yahan GitHub Pages ka link daalo, baad me]

## ✨ Features

- Clean hero section with rating badge, call-to-action buttons and "Trusted by" logos
- Navigation bar with glassmorphism-style buttons
- Accommodation cards showing image, rating, price, basic info, cleanliness and amenities
- **Circle fill hover effect** on info cards (colour expands smoothly from the centre using CSS `::before`, `transform: scale()` and `transition`)
- Rating badge placed on top-right corner of image cards
- **Fully responsive** layout for desktop, tablet (2 cards per row) and mobile (1 card per row) using media queries
- Hover effect disabled on touch devices using `@media (hover: none)`

## 🛠️ Tech Stack

- **HTML5**: page structure
- **CSS3**: Flexbox, positioning, pseudo-elements, transitions, media queries
- **Remix Icon**: icons
- **Google Fonts**: typography
